# SQUID SURVIVAL – Visual Reference Asset Pack

This ZIP contains the generated master reference sheet and category crops.

## Contents
- `00_full_asset_reference.png` – complete visual reference.
- `01_player_characters.png` – player character concepts.
- `02_guards.png` – guard concepts.
- `03_outfits_costumes.png` – outfit concepts.
- `04_masks_accessories.png` – masks and accessories.
- `05_boss_characters.png` – five boss concepts.
- `06_ui_elements.png` – menu and HUD visual concepts.
- `07_obstacles_traps.png` – obstacle and trap concepts.
- `08_stage_environments.png` – five stage environment concepts.
- `09_boss_battle_scenes.png` – boss arena concepts.
- `10_special_effects.png` – visual effect concepts.
- `11_victory_defeat_screens.png` – victory and defeat UI concepts.
- `12_achievements_rewards.png` – achievement and reward concepts.
- `13_powerups_collectibles_audio.png` – power-ups, collectibles and audio UI concepts.

## Important integration note
These are visual reference sheets/crops, not a production sprite library. The crops may include labels, panel borders, and multiple objects. They are not individually isolated transparent sprites, and the image does not contain 50 separate level backgrounds or animation frames.

Give this folder to Claude and ask it to use the images as art-direction references, then create or extract clean individual assets with transparent backgrounds where appropriate. Do not use the entire reference sheet as a single in-game texture.
